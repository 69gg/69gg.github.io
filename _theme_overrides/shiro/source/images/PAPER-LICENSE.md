# Paper texture attribution

`paper-fibers.webp` is a lossless WebP conversion of **Paper Fibers**, created by
**Heliodor Jalba**, originally published by Subtle Patterns and distributed in
transparent form by Transparent Textures.

- Author and texture: https://www.transparenttextures.com/paper-fibers.html
- Downloaded source: https://www.transparenttextures.com/patterns/paper-fibers.png
- Original collection: https://www.toptal.com/designers/subtlepatterns/
- Collection license statement: https://github.com/atlemo/SubtlePatterns/blob/gh-pages/README.md
- License: Creative Commons Attribution-ShareAlike 3.0 Unported
  https://creativecommons.org/licenses/by-sa/3.0/

The converted texture remains under CC BY-SA 3.0. Its pixels and transparency
are unchanged; CSS controls the display strength and reverses the tonal values
for dark mode. Attribution is also retained beside its CSS rule.

`paper-edge-*.svg` are separate, project-created decorative masks. Their edge
depth stays fixed in CSS pixels, so it does not stretch with long articles.
