# 山重水复疑无路
为了参加那个莫名奇妙被推荐过去的*中国‘芯’助力中国梦——全国青少年通信科技创新大赛*，我得麻烦一下我的钱包。比赛规则中要求必须使用国产的开发板，所以我还麻烦了我暑假里宝贵的脑细胞想一想应该买什么开发板。一开始我买的是火龙果的一个单片机开发板，然后这个3天不发货，我点进去一看，霍！店铺已打烊！我直接退款举报一套小连招外加马上打开咸鱼。
咸鱼上看了半天，选定了一款ch340g国产芯片的Arduino UNO。卖家说好的第二天上午发货，我晚上问他，他说忘掉了，正式气煞我也。50块钱，说好的给我发6片，又说忘了，只给我了5片，还好知道补发。

# 曲折终见Arduino
到货已经4天，不过效果非常好。让Gemini给我写了几行亮灯的代码，然后跟着B站一个教程配置好了CLion，C++写起来也比较轻松，不像那个汇编，写着左脑感觉这玩意太抽象，右脑觉得这玩意不能给我点抽象层吗？

# 我也只能亮个灯
我想该做些什么的时候，偶然间想起了《百年孤独》里面那个失忆的村子，不是贴标签吗，我就**一拍即合**，打算用NFC实现类似效果，具体的价值见下~~Claude写的~~：
```
近年来，我国人口老龄化加速，阿尔茨海默病患者数量持续增长。患者常常无法识别身边的人和物，给家庭带来沉重负担。本项目设计了一款基于Arduino和NFC技术的交互式语音记忆盒子，通过"触碰即播放"的简单交互，帮助患者唤醒记忆。项目选用国产YX5200语音芯片，实现了高性价比的解决方案。经测试，系统响应迅速、操作简单，特别适合认知能力下降的老年人使用。
```
于是我光速去买配件：
| 元件名称 | 备注 |
|---------|---------|
| MFRC522 | NFC读写模块 |
| DFPlayer Mini | 语音播放模块 |
| NFC标签贴纸 | NTAG213芯片 |
| Micro SD卡 | 1GB |
| 面包板 & 杜邦线 | 连接套装 |
| 迷你音箱 | 2W 8欧姆 |
| SI24R1 | 2.4G射频模块 |

买完之后，就只能等了，现在只能对着板子上仅有的一盏灯看了。剩下的等我东西到了再来叙述。
